# قائمة env المطلوبة على production (ops) — قبل/مع الإطلاق

> **لمين:** مسؤول سيرفر **الباك اند** (الهوستنجر بتاع `ivory-snail-183262`).
> **ليه:** الكود بيقرا المتغيّرات دي بالفعل — بس قيمها مش متحطوطة في env الإنتاج، فبتفضل معطّلة/غلط.
> بعد أي تغيير: `php artisan config:clear && php artisan route:clear` (بعضها متعلّق بالكونفيج/المسارات).

| # | المتغيّر | القيمة | من غيره بيحصل إيه | المرجع |
|---|---|---|---|---|
| 1 | `FRONTEND_URL` | `https://<دومين-الفرونت>` | روابط إعادة تعيين الباسورد في الإيميلات بتطلع `localhost`/غلط → المستخدم مش بيقدر يفعّل حسابه | `config/app.php:69` |
| 2 | `CORS_ALLOWED_ORIGINS` | `https://<دومين-الفرونت>` | الـCORS بيفضل fallback على `*` (مفتوح لأي origin) — غير آمن للإنتاج | `config/cors.php` |
| 3 | `FEATURE_ASAB_SUPPLIER_PORTAL` | `true` | مسارات بورتال المورد (`/api/v1/asab/supplier/*`) مش بتتسجّل → إضافة صنف بترجّع «تعذر الاتصال بالخادم» | `config/features.php` |

## بعد الضبط
```bash
php artisan config:clear
php artisan route:clear
# تأكيد مسارات بورتال المورد ظهرت (13 مسار):
php artisan route:list --path=asab/supplier
```

## ملاحظات (مش env — للمتابعة)
- **سعر أصناف بورتال المورد:** الفرونت بيبعت `priceHalalas` (هللات = ر.س × 100) ومبيبعتش `price` خام — فمفيش داعي لحقل `priceSar` جديد. خلّوا التخزين/القراءة بالهللة لاتساق باقي النظام.
- **ربط أصناف البورتال بموبايل المشتريات:** البورتال بيكتب في `asab_supplier_items` وموبايل المشتريات بيقرا من `supplier_items` — محتاج جسر (باك اند) زي BUG-9 عشان الصنف يظهر لمدير الفرع/موظف المشتريات.
