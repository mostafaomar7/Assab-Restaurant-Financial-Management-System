# طلب الفرونت للباك اند — 2026-07-26: مصدر «الفروع غير المربوطة»

> **من:** الفرونت · **إلى:** الباك اند
> عملت عرض `branchesLinked` + badge تحذير على كارت البراند. عشان أكمّل **زرار «اربط الفروع»** محتاج قائمة الفروع غير المربوطة — مش متاحة حاليًا.

## المشكلة
شجرة البراند بترجّع الفروع **تحت المطاعم** (المربوطة فقط). الفروع اللي `restaurant_id = null` مش بتظهر في أي مكان في الرد، فمعنديش الـ`id` بتاعها عشان أربطها عبر الـPATCH.

## المطلوب (أي خيار)
**خيار 1 (الأفضل) — endpoint للفروع غير المربوطة:**
```
GET /api/v1/admin/brands/{brandId}/branches?linked=false
→ [{ id, name, city? }]
```
(أو `GET /api/v1/admin/brands/{brandId}/unlinked-branches`)

**خيار 2 — ضمّنوها في شجرة البراند:**
حقل على مستوى البراند: `unlinkedBranches: [{ id, name }]`.

## تأكيد شكل الربط
هستخدم:
```
PATCH /api/v1/admin/branches/{id}
{ "restaurantId": "<restaurantId>" }
```
ده الشكل الصح لربط فرع بمطعم؟ ولا في حقل تاني؟

## بعد الرد
أبني زرار «اربط الفروع» (منتقي مطعم لكل فرع غير مربوط → PATCH → تحديث) في دقايق. باقي كل تحسينات 2026-07-26 خلصت في الفرونت.
